# Fișiere 3D (STL) - Poro 🐾

Acest director conține fișierele STL pentru imprimarea 3D a carcasei, mecanismelor și suporturilor robotului Poro.

## Listă piese

### Carcasă externă (Bază)
- **`Base_LeftDown.stl`** – Segment carcasă: stânga jos
- **`Base_LeftMiddle.stl`** – Segment carcasă: stânga mijloc
- **`Base_TopLeft.stl`** – Segment carcasă: stânga sus
- **`Base_RightDown.stl`** – Segment carcasă: dreapta jos
- **`Base_RightMiddle.stl`** – Segment carcasă: dreapta mijloc
- **`Base_TopRight.stl`** – Segment carcasă: dreapta sus

### Suporturi & Monturi
- **`Base_MountBig.stl`** – Element de fixare / montură mare pentru carcasă
- **`Base_MountSmall.stl`** – Element de fixare / montură mică pentru carcasă
- **`Support_ElectronicBase.stl`** – Suport intern pentru electronice (Raspberry Pi, controllere etc.)
- **`Support_ServoBig.stl`** – Suport pentru servomotor mare
- **`Support_ServoSmall.stl`** – Suport pentru servomotor mic

### Mecanism limbă
- **`Tongue_Reel.stl`** – Tambur / rolă pentru acționarea mecanismului limbii
